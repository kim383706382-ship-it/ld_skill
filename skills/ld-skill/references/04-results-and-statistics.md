# 结果叙述与统计呈现

## 来源、默认与事实保障分开
**来源观察：**A在Study 1/2结果中常用主题行内标题、组均值与SD、F/t/p及效应量；C多用分析目的引导自然段，并分述相反机制。三篇小数精度、前导零、区间写法及证据措辞并不完全一致。

**格式默认：**下面用于填补无指定稿件规范的外观规则，是本Skill的设计选择，不声称是三篇共同或某期刊最新标准。

**事实保障：**准确保留数值、模型、标签、区间和证据强度是执行边界，不是从范文的每一项统计实践推导来的结论。这里只组织实际分析输出，不替用户决定模型或补做未授权分析。

## 1. 以研究问题组织结果
结果模块通常包括最终样本或必要处理、相关检查、核心结果、机制与边界、实际已有补充分析。根据研究任务选择，不强迫每项都有所有模块。可采用变量或分析主题的行内标题；不要逐项复述软件菜单。

首次出现新分析，用一句说明它要检验哪一关系和实际模型；随后给最重要模式。具体比较通常采用：比较对象和方向 → 描述性统计 → 对应检验 → 对当前命题的有限结论。

例子A的Study 1a购买意愿段先说手表比香水高，再给M、SD、F、p、偏η²，最后回到H1a。C首次ANCOVA先写因素和控制变量，再解释结果。两种顺序互补，不需要每句固定开头。

## 2. 数字嵌入自然段
括号前先说明谁与谁、在哪一条件、哪个指标更高或更低。括号内各组描述统计与检验相互对应；不要让读者自己从均值猜方向。不要把不同模型的自由度、系数和p混在一组。

同一理论问题下多个因变量可以同段对照，让读者看出改变了什么和未检出什么。但模型、问题或主要机制转变时可另段；修改现有稿件涉及分段时先获批准。

正文给关键证据，表格供完整核对。表格已充分提供的全部控制变量不逐项朗读，但不能借“简洁”隐瞒与结论有关的相反结果。统计小结与理论解释分层，结果部分不提前扩展管理建议。

## 3. 均值比较与交互
总体模型写明实际主效应与交互；核心是交互时可以先报告交互，再补充其他效应，不为了统一句式颠倒解释重心。

交互之后解释形状。先沿假设关心的方向做已实施的简单比较，再在有必要时从另一方向补充。A提供了这种双向比较范例；但不能替任何交互都补出未做的全套检验。

连续调节写清探查取值及含义，保留“在该取值条件下”的性质，不改写为真实高低组。图表与正文中的取值、分组方向及条件简称一致。

多个结果支持力度不同时分开交代。没有交互检验的显著证据，不能仅凭一组显著、另一组不显著就写成已证明两组效应不同。这里是结论约束，不是增加某种方法的指令。

## 4. 回归、相关、趋势和补充结果
相关结果用关联措辞，不在段落改写时升级为因果。回归段先说明核心关系与模型，再解释系数所对应的变量变化；模型表承载完整结果。保持是否标准化、编码与单位的事实。

“平均模式—个体差异—进一步分析”是一种叙述可能性，不代表所有稿件都应事后分组或检验线性趋势。报告实际已有分析及它解决的问题；新分析列为建议，不冒充已完成。

稳健性与附加分析说明针对哪个解释疑问、改变了什么、结果相同在哪里及不同在哪里。结果材料只支持方向相近时，不写“所有证据完全一致”。

## 5. 中介与条件间接效应
模型介绍写清X、M、Y以及必要W、编码、协变量、实际软件与模型、重抽样和区间水平。可用自然语言或清楚的路径表达；正文仍须解释路径含义。

单中介首先交代间接效应与区间。机制推导有复杂环节时，可像C逐段补足X→M和M→Y的实际证据。路径检验不能取代间接效应检验，未报告的直接或总效应标为未提供。

并行中介分开叙述各条机制的方向与支持程度；相反的估计路径不能自动当作已经证明精确抵消。链式中介区分总间接效应、目标链及其他特定间接路径，不能混为同一数值。序列模型本身不能为所有心理先后关系提供额外因果授权。

条件间接效应、交互项与调节中介指数分清。保留整体检验与条件结果的不一致，不悄然改写源文，也不继承过强结论。

## 6. 不显著、有限支持与冲突
“不显著”写为当前分析未检出明确差异，不自动等于“相同”“没有任何作用”“证明等效”。除非相应实际证据足够，不作更强结论。假设支持、部分支持、未支持、未检验分别标明。

置信水平、显著性标准、单侧或双侧、校正方法保持实际设置；风格统一不能把90%改成95%，不能以结果为由切换标准。源文存在90%区间可如实讨论，但不设为默认的新研究分析。

原稿若将一个p=0.059称为显著而标准未交代，指出这一点并核对；不假定作者一定采用0.05，也不悄悄把数值改成0.049。先描述数字与原结论之间的问题，再根据已确认标准形成新表述。

遇到正文／表格／讨论矛盾，列出两个位置与差异，暂停受影响结论定稿，其余可继续。A Studies 2a/2b部分产品比较支持力度不同。不得以“学到了范文”作为复制问题的理由。

## 7. 无指定规范时的统一外观
已有稿件有明确且一致格式时先沿用；期刊或用户明确要求另行处理。下面只决定展示，不改变证据：

| 项目 | 新稿默认 |
|---|---|
| M、SD、年龄描述 | 通常两位小数；小量级变量需要更多精度时保留必要位数 |
| F、t、r、回归系数、SE、效应量 | 通常三位小数；真实输出不足精度不补造 |
| p值 | 前导零，通常三位；原输出仅提供阈值则保留阈值；不写p=0.000 |
| 置信区间 | 实际水平＋CI [下限, 上限]；必要时增加端点精度，不把小非零端点舍到0而掩盖意义 |
| 比较描述统计 | 各条件分别列M与SD；条件多或标签长时先定义简短标签 |
| 统计字母 | 拉丁统计符号按统计用途斜体；说明性条件下标不斜体；希腊字母区分处理 |
| 偏η²等 | 使用正确上／下标；纯文本无法呈现时使用清楚一致的等价写法 |
| 系数标识 | b、β及Effect按真实输出与定义使用，不将所有系数写成β |
| 星号 | 沿用已明确的阈值并在表注说明；未知时先用数值，不自动配置含义 |
| 数学格式 | 关系符两侧统一留空格；不把全文所有p或M机械设成统计符号 |

## 8. 一段可核对的双语结果示范
以下仅重新组织A Study 1a的原始报告数字，以展示同一结果的两种语言；不是新数据，也不是通用实验结果。保留原文三位数精度，因为是在转写现有报告而非从零指定样式。

中文：参与者对手表仿冒品的购买意愿高于香水仿冒品（手表：M = 2.514，SD = 1.225；香水：M = 2.046，SD = 1.165），F(1, 133) = 5.161，p = 0.025，ηₚ² = 0.037。该比较与H1a预测的方向一致。

English: Participants reported higher purchase intentions for the counterfeit watch (M = 2.514, SD = 1.225) than for the counterfeit perfume (M = 2.046, SD = 1.165), F(1, 133) = 5.161, p = 0.025, ηₚ² = 0.037. This comparison was consistent with the direction predicted in H1a.

学习点：先说比较含义、再提供可核对证据；英文与中文命题相同。原文的“H1a was supported”仍属于原文记录，示例收束属于此处适配，不伪称逐字引用。用于Word时须落实统计斜体与上下标。

## 9. 结果交付检查
比较方向与M相符；条件标签与编码相符；统计量、自由度、p、区间与同一模型对应；表图文数字一致；描述性、关联性、因果性措辞分明；未将证据有限写成没有局限；未因文风补造检验。
