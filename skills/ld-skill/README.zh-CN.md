# ld_skill｜中英文管理学论文写作

向助手提供稿件、相关批注和写作目标，调用 `$ld-skill` 后用自然语言说明需求即可，无须选择内部命令。

> 请使用 $ld-skill，结合批注、引言和结果修改这部分假设推导。保持构念、假设方向及证据强度；段落结构变更先提出具体方案。

本 Skill 支持引言、文献综述、理论与假设、方法、结果和讨论。只交付用户要求的语言。理论专项指导按任务读取，不将假设推导模板用于其他部分。

## 修改边界

原段落内可以优化表达和句序。移动、拆分、合并、增删段落或跨段转移内容，需要先获得对具体方案的批准。构念、机制、假设、事实、数据与证据强度不能作为文风调整擅自改变。已有授权继续有效，不重复询问。详见[修改权限](references/07-editing-permissions.md)。

## 安装与发现

项目级安装时，将完整 `ld-skill` 文件夹放入项目的 `.agents/skills/`，保留所有参考文件，不能只复制入口。旧安装先备份到技能扫描目录之外，再切换版本，避免重复入口。个人级安装是另一个范围，不随项目更新自动执行。

显示名为 `ld_skill`，内部名称和目录为 `ld-skill`。客户端中的技能选择入口依产品界面而定；也可明确要求使用 `$ld-skill`。发现异常时先刷新，再检查是否需要重启。[官方加载说明](https://learn.chatgpt.com/docs/build-skills)。

安装完成须核对实际读取路径、版本及一次真实调用。下载文件、名称出现在回复中或静态检查通过都不能代替调用验证。
